# Huipil Uzumaki de Vela

Diseño de un **huipil ceremonial para hombre** del Istmo de Tehuantepec (Oaxaca) con signos de *Naruto* pasados a bordado floral.

- Lookbook: [diseno/lookbook.html](diseno/lookbook.html)
- Ficha de corte, paleta y motivos: [diseno/ficha-de-diseno.md](diseno/ficha-de-diseno.md)
- Láminas: [diseno/laminas](diseno/laminas)

No es un traje de tehuana ni reemplaza la guayabera de vela. Es una túnica contemporánea que usa la gramática del huipil de gala (terciopelo negro, yugo de flores, cadenilla) y se porta con pantalón negro, paliacate y sombrero de palma.
